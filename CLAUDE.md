## Overview

This is a Spacemacs configuration repository. It contains a single file, `init.el`, which is the primary Spacemacs dotfile loaded at startup.

## Applying Configuration Changes

After editing `init.el`, reload the configuration inside Spacemacs:

- **Reload entire config**: `SPC f e R` (Vim style) or `M-m f e R` (Emacs style)
- **Evaluate a single expression**: place cursor on the expression and press `SPC m e e` (in `emacs-lisp-mode`)
- **Restart Emacs**: `SPC q r`

## Structure of `init.el`

The file is organized into four required Spacemacs functions:

- **`dotspacemacs/layers`** — Declares which layers and additional packages are loaded. Add/remove layers or packages here.
- **`dotspacemacs/init`** — Core Spacemacs settings (font, theme, editing style, UI options). Modifies `dotspacemacs-*` variables only.
- **`dotspacemacs/user-init`** — User variables set before layer loading. Rarely needed.
- **`dotspacemacs/user-config`** — All custom user configuration, run after layers load. This is where hooks, custom functions, and package configuration live.
- **`dotspacemacs/emacs-custom-settings`** — Auto-generated by Emacs `customize`. Do not edit manually.

## Key Configuration Details

**Editing style**: Vim (`dotspacemacs-editing-style 'vim`). Leader key is `SPC`.

**Active layers**: `syntax-checking`, `auto-completion`, `colors`, `html`, `emacs-lisp`, `git`, `ivy`, `lsp`, `markdown`, `org`, `pdf`, `shell` (vterm), `spotify`, `treemacs`, `java`, `yaml`, `themes-megapack`, `multiple-cursors`.

**Additional packages** (outside layers): `nerd-icons`, `nerd-icons-dired`, `nerd-icons-ibuffer`, `nerd-icons-completion`, `treemacs-nerd-icons`, `nerd-icons-ivy-rich`, `chordpro-mode`.

**Theme**: `doom-molokai` (set via `custom-set-variables`). The `dotspacemacs-themes` list is a fallback.

**Font**: JetBrainsMono Nerd Font, 11pt.

## Org-mode Setup

- **Agenda source**: Files are loaded dynamically from `~/workspace/journal/**/*.org`
- **TODO states**: `TODO` → `SCHEDULED` → `NEXT` → `ACTIVE` → `PAUSED` → `DONE` / `DECLINED`
- **Priorities**: A (green) → B (magenta) → C (orange) → D (yellow)
- **Pomodoro**: 60-min work sessions, 5-min short break. `org-pomodoro-5` is a custom command for 5-min sessions.
- **Auto-completion**: Parent headings inherit TODO state changes from children via `my/org-after-todo-state-change-hook`.

## Adding New Packages

To add a package not part of a layer, append it to `dotspacemacs-additional-packages` in `dotspacemacs/layers`, then configure it in `dotspacemacs/user-config` using `require` or `use-package`.
